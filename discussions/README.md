# Discussion preservation
Recorded 23-Oct-2026. Migration draft.

This folder preserves available topic history. Current standards live in `standards/`; discussions are evidence, not a second editable standard. Earlier suggestions are retained and classified.

## Coverage
- `user-excerpts.json`: selected exact user messages/fragments visible to this task; no invented timestamps or provider IDs.
- `topic-history.md`: explicitly labelled retrospective summary of architecture, naming, features, comparisons and migration decisions.
- `../migration/source-snapshot.json`: readable values from all 44 existing register tabs, including decision/change history.
- `../migration/source-docs.json`: readable source-document snapshots.

## Limits
This is not a complete provider transcript. A complete original export, earlier original assistant messages and exact message timestamps are unavailable here. Unrelated earlier payroll discussions are not represented as new governance requirements. Future discussion records should preserve original text, source link/ID where available, speaker, status, decision links and supersedes references. Never fabricate missing messages.

## Change policy
Append corrections and superseding decisions; preserve historical wording. Do not overwrite an old proposal to make it appear it always matched the accepted rule. No GitHub Discussions feature was enabled; these are versioned repository files.
