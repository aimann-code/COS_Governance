# Proposed user operation guide

Stage: Draft | Working user: Ashish | Recorded: 29-Oct-2026

These are target workflows, not instructions for an existing deployed application.

1. Select an authorized entity and configured source location or upload a report.
2. Confirm source registration and preserved-original reference.
3. Review selected Report Profile/layout; ambiguous or unsupported layouts require a profile review.
4. Start processing and monitor its durable run reference.
5. Review coverage, unknown fields, conversion errors, duplicate/conflicting observations and master mappings.
6. Correct configuration through versioned review, then rerun affected scope. Preserve previous evidence.
7. Run compatible reconciliations and review proposed matches, residual balances and exceptions.
8. Inspect GST/TDS working and accounting previews under the approved treatment.
9. Obtain required approval for the exact accounting payload. Export or submit only with appropriate permission.
10. Inspect submission response/readback, external IDs and accounting reconciliation.
11. Generate reports displaying scope, period, grain, run, source completeness and unresolved exceptions.

Not supplied / not checked means evidence is missing. Review/Fail records require explicit disposition. Completed with exceptions does not mean every financial record is ready. A balanced preview does not imply posted or reconciled.

Withdrawals and copied summaries are not additional sales. Resolve unknown masters through reviewed mapping; do not invent entities or infer tax treatment.

Troubleshooting: unsupported layout → profile review; missing source → check direct listing/access and expected period; source error → obtain corrected evidence; ambiguity → review candidates; unknown posting result → accounting readback before retry.

Actual buttons, screen labels, roles and operating schedules depend on implementation and acceptance.
